# Changelog

All notable changes to this project will be documented in this file.

## 0.1.0 - 2026-08-17

### Added

- Chrome Manifest V3 extension with paragraph extraction and bilingual DOM insertion.
- Eight target languages and one-click page restoration.
- Local Chrome Native Messaging bridge to the Codex CLI.
- Ephemeral, read-only Codex execution with disabled non-translation tools.
- Strict input validation and JSON Schema output validation.
- Stable unpacked-extension ID and macOS native-host installer.
- Mock protocol tests, local demo article, English and Chinese documentation.
