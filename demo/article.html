Reading the web without leaving the original behind

Translation tools are often designed to replace a page. A bilingual reader takes a different approach: it keeps the source visible and places the translation close enough to compare.

This small difference changes the experience. Names remain recognizable, technical terms can be checked, and the rhythm of the original text is not completely lost.

The goal is not to hide the foreign language. The goal is to make it approachable.

A deliberately small first version

The prototype translates headings, paragraphs, quotations, and list items. It ignores navigation, forms, code blocks, and other interface text that would make the page noisy.

  • The original document remains untouched.
  • Each translated block can be removed in one click.
  • Page text is treated as untrusted input.
